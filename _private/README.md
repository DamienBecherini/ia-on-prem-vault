Place **confidential** notes here — they will not be pushed to GitHub or built into the static site.

- Every file in `_private/` (except this README) is **gitignored** and **excluded from the Astro build**.
- You can add other paths in the vault [`.gitignore`](../.gitignore); the engine excludes those the same way.

This README is the only file in this folder tracked on GitHub; it documents the convention.
