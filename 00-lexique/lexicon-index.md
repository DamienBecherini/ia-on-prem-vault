title: Index du lexique
description: Liste alphabétique de toutes les fiches du lexique IA on-premise.
---

Liste générée automatiquement au build. Pour une lecture guidée, voir [[00-lexique/ai-glossary|Glossaire IA]].

- [[00-lexique/autonomous-agent|Agent autonome (LLM)]] — Système où un LLM pilote lui-même des outils et des décisions pour accomplir une tâche multi-étapes.
- [[00-lexique/agent-custodian|Agent custodien]] — Agent autonome chargé de maintenir un vault, dépôt ou corpus documentaire en proposant des corrections validées par l'humain.
- [[00-lexique/apu|APU]] — Puce combinant CPU, GPU et NPU sur un même SoC, avec mémoire unifiée partagée.
- [[00-lexique/attention|Attention (mécanisme)]] — Mécanisme central du Transformer qui permet à chaque token de pondérer l'importance des autres tokens du contexte.
- [[00-lexique/memory-bandwidth|Bande passante mémoire]] — Débit auquel la mémoire alimente les unités de calcul.
- [[00-lexique/vectordb|Base de données vectorielle]] — Base de données spécialisée dans le stockage et la recherche de vecteurs d'embeddings pour le RAG.
- [[00-lexique/decoding|Decoding]] — Phase de génération auto-régressive token par token.
- [[00-lexique/ecn|ECN]] — Explicit Congestion Notification — mécanisme de signalement de congestion réseau utilisé avec RoCE pour éviter les pertes de paquets.
- [[00-lexique/embedding|Embedding]] — Représentation numérique dense d'un token ou d'un document dans un espace vectoriel.
- [[00-lexique/exo|Exo]] — Orchestrateur P2P open-source pour fusionner la mémoire de plusieurs machines en un cluster IA local.
- [[00-lexique/context-window|Fenêtre de contexte]] — Nombre maximal de tokens qu'un LLM peut traiter en entrée active — détermine le coût mémoire dynamique de l'inférence.
- [[00-lexique/gguf|GGUF]] — Format de fichier portable pour l'inférence locale avec llama.cpp, optimisé pour les quantifications K-quant.
- [[00-lexique/gpudirect-rdma|GPUDirect RDMA]] — Mécanisme permettant aux GPU d'échanger des données directement avec des périphériques réseau sans copie CPU.
- [[00-lexique/graphrag|GraphRAG]] — Évolution du RAG basée sur un graphe de connaissances plutôt qu'une base vectorielle.
- [[00-lexique/hbm|HBM]] — Mémoire empilée à très haute bande passante, utilisée sur les accélérateurs IA professionnels.
- [[00-lexique/human-in-the-loop|Human-in-the-loop]] — Mode de gouvernance où une action automatisée importante attend une validation humaine avant d'être appliquée.
- [[00-lexique/inference|Inférence (LLM)]] — Utilisation d'un modèle entraîné pour générer du texte à la demande.
- [[00-lexique/infiniband|InfiniBand]] — Fabric réseau dédié hautes performances pour les clusters GPU, standard HPC et datacenter IA.
- [[00-lexique/kv-cache|KV Cache]] — Cache des clés/valeurs d'attention utilisé pendant la génération.
- [[00-lexique/litellm|LiteLLM]] — Gateway OpenAI-compatible qui route les appels LLM vers des modèles locaux ou cloud depuis une interface unique.
- [[00-lexique/llm|LLM]] — Large Language Model.
- [[00-lexique/unified-memory|Mémoire unifiée]] — Architecture mémoire partagée entre CPU/GPU/NPU.
- [[00-lexique/memory-tree|Memory Tree]] — Architecture mémoire qui organise documents et résumés en arbre hiérarchique pour limiter le contexte injecté au LLM.
- [[00-lexique/memory-wall|Memory Wall]] — Limite de performance causée par la mémoire plus que par le calcul.
- [[00-lexique/moe|MoE]] — Mixture of Experts — architecture où seuls certains sous-réseaux sont activés par token, permettant des modèles énormes avec un coût d'inférence maîtrisé.
- [[00-lexique/multi-gpu|Multi-GPU]] — Utilisation conjointe de plusieurs GPU.
- [[00-lexique/nccl|NCCL]] — Bibliothèque NVIDIA de communication collective optimisée pour les transferts GPU-à-GPU à grande échelle.
- [[00-lexique/npu|NPU]] — Neural Processing Unit — accélérateur spécialisé IA intégré aux SoC modernes, utile pour certaines tâches mais limité pour les grands LLM.
- [[00-lexique/nvlink|NVLink]] — Interconnexion haut débit entre GPU NVIDIA.
- [[00-lexique/nvswitch|NVSwitch]] — Commutateur NVIDIA qui connecte plusieurs GPU en un fabric NVLink totalement non bloquant à l'intérieur d'un nœud.
- [[00-lexique/offloading|Offloading]] — Technique qui place une partie du modèle en RAM ou sur SSD quand la VRAM est insuffisante, au prix d'un débit réduit.
- [[00-lexique/on-premise|On-Premise (IA)]] — Infrastructure IA hébergée et opérée sur les équipements propres de l'organisation, sans délégation à un fournisseur cloud.
- [[00-lexique/pagedattention|PagedAttention]] — Technique de gestion du KV Cache par blocs de mémoire virtuelle, popularisée par vLLM.
- [[00-lexique/pcie|PCIe]] — Bus d'interconnexion haut débit entre composants.
- [[00-lexique/pfc|PFC]] — Priority Flow Control — mécanisme Ethernet de pause par priorité pour garantir un réseau lossless nécessaire à RoCE.
- [[00-lexique/pipeline-parallelism|Pipeline Parallelism]] — Stratégie de distribution d'un LLM en tranches de couches entre plusieurs machines.
- [[00-lexique/prefill|Prefill]] — Phase d'inférence qui traite le prompt initial en parallèle avant la génération mot à mot.
- [[00-lexique/quantification|Quantification]] — Réduction de précision numérique des poids d'un LLM pour diminuer l'empreinte mémoire et accélérer l'inférence.
- [[00-lexique/quantification-q4|Quantification Q4]] — Format de quantification 4-bit le plus utilisé en pratique pour l'inférence locale — en particulier Q4_K_M dans l'écosystème GGUF/Ollama.
- [[00-lexique/rag|RAG]] — Architecture qui combine recherche documentaire et génération LLM.
- [[00-lexique/ram|RAM]] — Mémoire vive système, second choix pour l'inférence LLM quand la VRAM est insuffisante.
- [[00-lexique/ray|Ray]] — Framework de calcul distribué pour l'orchestration multi-nœuds de LLM en production.
- [[00-lexique/rdma|RDMA]] — Accès mémoire distant direct sans copie CPU classique.
- [[00-lexique/roce|RoCE]] — Implémentation d'RDMA sur Ethernet convergé.
- [[00-lexique/smolagents|SmolAgents]] — Framework léger de Hugging Face pour l'orchestration agentique locale, alternative souveraine à LangChain.
- [[00-lexique/tensor-parallelism|Tensor Parallelism]] — Stratégie de distribution d'un LLM par découpage des matrices mathématiques entre plusieurs GPU d'un même nœud.
- [[00-lexique/tensorrt-llm|TensorRT-LLM]] — SDK NVIDIA de compilation et d'inférence ultra-optimisée pour GPU datacenter.
- [[00-lexique/tflops|TFLOPS]] — Mesure de débit de calcul en opérations flottantes.
- [[00-lexique/thunderbolt|Thunderbolt]] — Interface câblée haut débit pour postes de travail et clusters de bureau IA.
- [[00-lexique/tokenisation|Tokenisation]] — Découpage d'un texte en unités numériques (tokens) avant traitement par un LLM.
- [[00-lexique/tokens-per-second|Tokens par seconde]] — Mesure du débit de génération d'un modèle.
- [[00-lexique/ttft|TTFT]] — Time To First Token.
- [[00-lexique/vram|VRAM]] — Mémoire vidéo dédiée au GPU.
