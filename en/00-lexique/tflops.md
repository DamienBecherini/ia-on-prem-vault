## 📝 Short definition
Unit measuring floating-point compute capacity per second.

## 📖 Detailed definition
TFLOPS is useful for comparing raw compute potential, but it is not a sufficient predictor of LLM performance.
In autoregressive inference, memory and data movement can dominate.

## 💡 Why it matters for on-prem AI
Avoids sizing mistakes: a machine very strong in TFLOPS can still be slow if memory bandwidth is low.
