# Agent plans

Active implementation plans for multi-step agent work (refresh runs, chapter generation, migrations). One Markdown file per plan, named `<YYYY-MM-DD>-<kebab-topic>.md`.

Plans are working files: they are **gitignored** (only this README is tracked) and excluded from publication. The durable audit trail is the PR description and, for refresh runs, the reports in `.agents/vault-maintenance/reports/`.

Cursor creates plans in `.cursor/plans/` by default; move them here when they become the reference for a task.
